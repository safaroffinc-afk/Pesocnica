# Техническое задание: Multi-Asset AI Crypto Signal Terminal (MAST)

- Версия: 1.0
- Дата: 15.03.2026
- Целевые активы: TON, BTC, SOL, BNB, XRP

## Цель
Создать аналитическую платформу, которая объединяет рыночные, on-chain и сентимент-данные для генерации сигналов BUY/HOLD/SELL и целевых уровней на кратко- и долгосрочном горизонте.

## Архитектура

### 1) Data Aggregation Layer
- Realtime-данные бирж: Binance, OKX, Kraken (стаканы, объёмы, OI).
- On-chain источники: активность крупных кошельков, комиссии, активность dev-команд.
- News & macro ленты: события, влияющие на рынок.

### 2) Multi-Factor Intelligence
- Технический анализ (50+ индикаторов, свечи, уровни поддержки/сопротивления).
- Фундаментальный анализ с актив-специфичными факторами.
- Сентимент-анализ (новости + соцсети + Fear & Greed).

### 3) Execution & Signal Layer
- Сигнал усиливается, когда TA + фундаментал + сентимент совпадают.
- Автообновление таргетов для 2026 и 2027–2030.
- Опционально: автосделки через API бирж.

## Актив-специфика
- BTC: ETF-флоу, хешрейт, макро-фон.
- SOL: микроплатежи, stablecoin-активность, комиссии.
- XRP: SEC/регуляторный контекст, RippleNet adoption.
- BNB: Auto-Burn, TVL BNB Chain, активность dApps.
- TON: интеграция с Telegram, активность каналов/ботов, скорость сети.

## UI/UX требования
- Единый дашборд по сигналам на 5 активов.
- Графики с индикаторами.
- История сигналов и бэктест.
- Уведомления в Telegram/e-mail.

## Технический стек
- Python (аналитика/бэкенд), JavaScript (фронтенд).
- PostgreSQL или InfluxDB для исторических рядов.
- Local-first защита API-ключей.
- Масштабируемая архитектура для добавления новых монет.
